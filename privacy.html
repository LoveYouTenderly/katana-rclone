Privacy policy - katana-rclone

Last updated: 28 September 2026

  • katana-rclone is used only by its owner. It is not offered to anyone else.
  • It uses the Google Drive drive.file scope to upload files that it creates into the owner's own Google Drive. It cannot see any other files.
  • No personal data is collected, sold, or shared with third parties. Google user data is used only to upload the owner's own files.
  • The OAuth token is stored only in the owner's rclone configuration file. Access can be revoked at any time at https://myaccount.google.com/permissions.
  • Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
